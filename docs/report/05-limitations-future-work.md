# 5. Limitations & Future Work — ข้อจำกัดของระบบและแนวทางการพัฒนาในอนาคต

## 5.1 ข้อจำกัดของระบบในปัจจุบัน (System Limitations 3 ด้าน)

การประเมินข้อจำกัดอย่างตรงไปตรงมาตามหลักวิชาการช่วยให้ผู้ใช้งานและผู้ประเมินเข้าใจขอบเขตความสามารถที่แท้จริงของระบบ:

### 5.1.1 ข้อจำกัดทางเทคนิค (Technical Limitations)
1. **สถานะความเป็น Local Simulation:** ระบบในโครงการนี้เป็นการจำลองกลไกบล็อกเชน (Local Blockchain Simulation) ด้วยอัลกอริทึม SHA-256 + Ed25519 PoA บนกระบวนการทำงานของ Nuxt 4 และตาราง PostgreSQL เดี่ยว ไม่ใช่เครือข่าย Distributed Network หลายเครื่องจริง
2. **การทำงานของ Validator โหนด:** โหนดผู้ตรวจสอบทั้ง 3 ฝ่าย (`COOPERATIVE_AUTHORITY`, `LOCAL_CERTIFIER_AUTHORITY`, `RETAIL_NETWORK_AUTHORITY`) ทำงานอยู่ภายในแอปพลิเคชันและฐานข้อมูลเดียวกันเพื่อการศึกษาและสาธิตเชิงสถาปัตยกรรม (Proof of Concept)
3. **การเข้าถึงอินเทอร์เน็ตในชนบท:** การส่งคำขอและการตรวจรับรองจำเป็นต้องมีการเชื่อมต่ออินเทอร์เน็ต ซึ่งในบางพื้นที่ห่างไกลของบุรีรัมย์อาจมีสัญญาณไม่เสถียร

### 5.1.2 ข้อจำกัดทางการเงินและต้นทุน (Financial Limitations)
1. **งบประมาณในการจัดตั้งโครงสร้างพื้นฐานจริง:** หากต้องการยกระดับเป็นเครือข่ายบล็อกเชนแบบกระจายศูนย์จริงระหว่างองค์กร จะต้องมีค่าใช้จ่ายเซิร์ฟเวอร์แยกแต่ละหน่วยงาน ค่าบำรุงรักษาระบบเครือข่าย และค่าอุปกรณ์ฮาร์ดแวร์ความปลอดภัย (Hardware Security Module: HSM) สำหรับเก็บรักษา Private Key ของแต่ละองค์กร
2. **ต้นทุนวัสดุติดแท็กบนผืนผ้า:** ปัจจุบันใช้เพียงป้าย QR Code กระดาษ/สติกเกอร์ หากต้องการใช้เทคโนโลยีป้องกันการปลอมแปลงขั้นสูง เช่น ชิป NFC ฝังในเส้นไหม หรือแท็ก RFID แบบทนความร้อน จะมีต้นทุนเพิ่มขึ้น 10–50 บาทต่อผืนผ้า

### 5.1.3 ข้อจำกัดด้านกฎระเบียบและการยอมรับ (Regulatory & Adoption Limitations)
1. **การยอมรับทางกฎหมายของใบรับรอง:** ใบรับรองดิจิทัลนี้เป็นการรับรองภายในกลุ่มพันธมิตรวิสาหกิจชุมชน ยังไม่มีสถานะเป็นใบรับรองมาตรฐานสินค้าสิ่งทออย่างเป็นทางการในระดับสากล (เว้นแต่จะได้รับการรับรองร่วมกับตรานกยูงพระราชทานของกรมหม่อนไหม)
2. **การปรับตัวของสมาชิกชุมชน:** ต้องใช้เวลาในการสร้างความคุ้นเคยและปรับเปลี่ยนพฤติกรรมของช่างทอจากการบันทึกด้วยสมุดกระดาษมาสู่ระบบดิจิทัล

## 5.2 ปัญหาตัวเชื่อมข้อมูลกายภาพและดิจิทัล: Oracle Problem & Garbage-in-Garbage-out (GIGO)

> [!WARNING]
> **ความจริงพื้นฐานของเทคโนโลยีบล็อกเชน:** บล็อกเชนรับประกันเฉพาะ **"ความถูกต้องสมบูรณ์ของการบันทึกข้อมูล (Data Integrity & Non-repudiation)"** แต่บล็อกเชน **"ไม่สามารถรับประกันความจริงทางกายภาพของวัตถุภายนอก (Physical Truth)"** ได้ด้วยตัวเอง

* **ปัญหา Garbage-in-Garbage-out (GIGO):** หากช่างทอหรือผู้ตรวจรับรองกรอกข้อมูลเท็จตั้งแต่ต้น เช่น นำผ้าไหมผสมใยสังเคราะห์มาลงทะเบียนว่าเป็นผ้าไหมแท้ 100% บล็อกเชนจะบันทึกข้อมูลเท็จนั้นไว้อย่างถาวรและแก้ไขไม่ได้
* **มาตรการบรรเทาปัญหา (Mitigation Measures):**
  1. บังคับให้มีกระบวนการตรวจสอบทางกายภาพ (Physical Inspection) โดยเจ้าหน้าที่สหกรณ์ก่อนการอนุมัติออกบล็อก
  2. จัดเก็บภาพถ่ายขั้นตอนการสาวไหมและการทอเป็นหลักฐานประกอบ (Evidence-backed Attestation)
  3. บันทึกตัวตนของผู้ตรวจรับรองลงในบล็อกอย่างชัดเจน เพื่อให้สามารถสืบย้อนหาความรับผิดชอบ (Accountability) ได้หากพบการทุจริตในภายหลัง

## 5.3 ปัญหาการคัดลอก QR Code (QR Code Duplication Problem)

QR Code เป็นเพียง **"ตัวชี้ดิจิทัล (Digital Pointer)"** ไปยัง URL หน้าตรวจสอบ ไม่ใช่วัตถุป้องกันการปลอมแปลงในตัวเอง:

1. **ลักษณะของช่องโหว่:** ผู้ไม่หวังดีสามารถถ่ายภาพ QR Code จากผ้าไหมแท้ผืนหนึ่ง แล้วนำไปพิมพ์ติดลงบนผ้าไหมเทียมอีกผืนหนึ่งได้ เมื่อผู้ซื้อสแกน QR Code ก็จะยังเห็นข้อมูลใบรับรองที่ถูกต้องบนระบบ
2. **กลยุทธ์การป้องกันและตรวจสอบของระบบ:**
   * **การยืนยันรายละเอียดเฉพาะของผืนผ้า (Physical Attribute Matching):** หน้าเว็บตรวจสอบจะแสดงภาพถ่ายความละเอียดสูงของลายผ้า ผืนผ้า ขนาด และน้ำหนัก เพื่อให้ผู้ซื้อสามารถเปรียบเทียบผ้าจริงในมือกับภาพที่บันทึกไว้ในระบบได้
   * **ระบบติดตามประวัติการครอบครอง (Custody Chain):** ผู้ซื้อสามารถตรวจสอบได้ว่าร้านค้าที่ตนกำลังซื้ออยู่นั้น ได้รับมอบผ้าไหมผืนนี้มาอย่างถูกต้องในระบบหรือไม่
   * **คำแนะนำผู้บริโภค:** หน้าเว็บมีการติดป้ายเตือนและให้ความรู้แก่ผู้บริโภคในการสังเกตลักษณะทางกายภาพร่วมกับการสแกน QR Code

## 5.4 แผนงานและแนวทางการพัฒนาในอนาคต (Future Work Roadmap)

เพื่อให้ระบบสามารถก้าวสู่การใช้งานจริงในระดับจังหวัดและระดับประเทศ ทีมงานได้วางแนวทางการพัฒนาต่อยอดดังนี้:

| ระยะการพัฒนา (Phase) | รายละเอียดและเป้าหมายการดำเนินงาน | เทคโนโลยีและพันธมิตรที่เกี่ยวข้อง |
|---|---|---|
| **Phase 1: Real Pilot Deployment** | • ทดลองใช้งานนำร่องร่วมกับสหกรณ์ผ้าไหมบ้านหัวสะพาน และกลุ่มตุ้มทอง อำเภอนาโพธิ์<br>• นำเข้าข้อมูลจริงของช่างทอ 50–100 ราย | • สหกรณ์การเกษตรทอผ้าไหม<br>• สำนักงานพัฒนาชุมชนจังหวัดบุรีรัมย์ |
| **Phase 2: Multi-Node Consortium Network** | • แยกโหนด Validator ติดตั้งบนเซิร์ฟเวอร์ของแต่ละหน่วยงานจริง (สหกรณ์, พาณิชย์จังหวัด, สมาคมร้านค้า)<br>• พัฒนาเครือข่ายบล็อกเชนแบบ Hyperledger Fabric หรือ Quorum | • Cloud Nodes แยกตามองค์กร<br>• Docker Swarm / Kubernetes |
| **Phase 3: Advanced Physical Anti-Counterfeiting** | • นำเทคโนโลยี NFC Tag แบบทนน้ำและซักล้างได้มาเย็บฝังในชายผ้าไหม พร้อมชิปเข้ารหัสป้องกันการคัดลอก (Cryptographic Secure Element)<br>• การเชื่อมต่อกับฐานข้อมูลตรานกยูงพระราชทานของกรมหม่อนไหม | • Secure NFC Type 4 / 5<br>• กรมหม่อนไหม กระทรวงเกษตรฯ |
| **Phase 4: Mobile Application for Weavers** | • พัฒนาแอปพลิเคชันมือถือแบบรองรับ Offline-first สำหรับช่างทอในพื้นที่ชนบท พร้อมระบบถ่ายภาพและสแกนอัตโนมัติ | • Flutter / PWA<br>• Edge Storage & Sync |
