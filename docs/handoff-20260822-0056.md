## Verification performed

ตรวจ backend ด้วยการทดสอบจริง ไม่ใช่แค่อ่านโค้ด:
- login ผิด→401 / ถูก→session · ไม่ login→401 · weaver ยืม API สหกรณ์→403
- public cert: VALID/NOT_FOUND ถูก · **สแกน PII (email/เบอร์/hash) ไม่มีหลุด**

## Blockers and risks

1. **Docker validator-key (จะพังตอน Demo):** seed รันใน container `migrate` (one-shot แล้วตาย) → Ed25519 private key ที่สร้างตอน seed หายไปกับ container → container `app` ไม่มี key ไป sign block → **approve/transfer จะพังใน Docker แม้ dev ปกติ** — มอบหมายสมาชิก 4 แก้ด้วย named volume mount `storage/validator-keys` ทั้ง service migrate + app พร้อม `VALIDATOR_KEY_DIR` (รายละเอียดใน `06-next-steps.md` §4.1)
2. `ledger.service` เป็น mock — `pnpm ledger:verify` (ยังไม่มี script) และผล verify ทั้งระบบยังปลอม จนกว่าสมาชิก 4 ส่งงาน
3. สมาชิก 3 แตะไฟล์เกินเขต: `app/composables/useToast.ts` (stub 19 บรรทัด — ของสมาชิก 2), `AppHeader.vue`, `layouts/default.vue` → เตือนสมาชิก 2 ให้ทำต่อจาก stub และระวัง conflict ตอน merge
4. ไฟล์แก้ 5 ตัวยังไม่ commit บน branch `ิbackend`
