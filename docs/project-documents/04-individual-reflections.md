# แบบสะท้อนคิดรายบุคคล (Individual Reflections)

> **รายวิชา:** 4124301 เทคโนโลยีบล็อกเชนและการเข้ารหัสลับ  
> **ข้อกำหนด:** สมาชิกทุกคนเขียนสะท้อนคิดเกี่ยวกับการเรียนรู้ การทำงานร่วมกัน และอุปสรรค (ความยาว 5–10 บรรทัดต่อคน)

---

### 1. สมาชิกคนที่ 1: Business Analyst & Documentation Lead
> "การทำโครงงานนี้ทำให้ผมเข้าใจอย่างลึกซึ้งว่า เทคโนโลยีบล็อกเชนไม่ได้เป็นคำตอบสำหรับทุกปัญหา แต่ต้องเริ่มจากการวิเคราะห์ปัญหาความไว้วางใจ (Trust Problem) ข้ามองค์กรเป็นหลัก การได้ค้นคว้าข้อมูลจริงของกลุ่มทอผ้าไหมในอำเภอพุทไธสงและนาโพธิ์ ทำให้เห็นภาพชัดเจนว่าใบรับรองกระดาษแบบเดิมมีช่องว่างอย่างไร และทำไมระบบ SQL ธรรมดาถึงอาจไม่เพียงพอเมื่อมีหลายองค์กรเข้ามาเกี่ยวข้อง นอกจากนี้ การออกแบบระบบให้สอดคล้องกับ PDPA โดยแยกข้อมูล On-chain และ Off-chain เป็นประสบการณ์ที่มีคุณค่ามากในการเชื่อมโยงทฤษฎีเทคโนโลยีเข้ากับบริบทกฎหมายจริง"

---

### 2. สมาชิกคนที่ 2: Frontend Developer & UI/UX Specialist
> "ความท้าทายหลักของผมในโครงงานนี้คือ การออกแบบส่วนติดต่อผู้ใช้ (UI/UX) ด้วย Nuxt 4 และ Tailwind CSS ให้ช่างทอผ้าไหมซึ่งส่วนใหญ่เป็นผู้สูงอายุสามารถใช้งานได้ง่ายและไม่ซับซ้อน ผมได้เรียนรู้การนำ Design Tokens และ Semantic Colors มาปรับใช้ให้เข้ากับเอกลักษณ์หัตถกรรมไทย พร้อมทั้งพัฒนาหน้า Public Verification และ Blockchain Explorer ที่ช่วยให้ผู้บริโภคทั่วไปสามารถตรวจสอบความถูกต้องของสายโซ่บล็อก (Chain Integrity) ได้อย่างโปร่งใส การได้ทำงานร่วมกับทีมและเชื่อมต่อ UI เข้ากับ Backend API ทำให้ผมเข้าใจขั้นตอนการพัฒนาเว็บแอปพลิเคชันยุคใหม่อย่างครบวงจร"

---

### 3. สมาชิกคนที่ 3: Backend & API Engineer
> "การรับผิดชอบงานส่วน Backend ด้วย Nitro Server API และ PostgreSQL 17 ทำให้ผมได้ฝึกฝนการออกแบบฐานข้อมูลแบบ Relational ที่ต้องทำงานสอดประสานกับระบบ Append-only Ledger อย่างราบรื่น สิ่งสำคัญที่สุดที่ได้เรียนรู้คือการรักษาความเป็น Atomic Transaction โดยการเขียนบันทึกทางธุรกิจและการลงนามบล็อกจะต้องสำเร็จพร้อมกัน หากขั้นตอนใดล้มเหลวจะต้อง Rollback ทั้งหมดเพื่อป้องกันข้อมูลไม่ตรงกัน นอกจากนี้ การนำ Idempotency Key และการตรวจสอบสิทธิ์แบบ RBAC มาใช้งานอย่างเข้มงวด ช่วยเสริมสร้างความปลอดภัยและความเสถียรของระบบอย่างแท้จริง"

---

### 4. สมาชิกคนที่ 4: Blockchain & QA Engineer
> "โครงงานนี้เปิดโอกาสให้ผมได้นำอัลกอริทึมการเข้ารหัสลับมาประยุกต์ใช้จริง โดยการสร้าง Local Consortium Blockchain Simulator ด้วย SHA-256 Hash Chain, Ed25519 Signatures และกลไกฉันทามติ Proof of Authority (PoA) แบบ Round-Robin ผมได้เข้าใจอย่างถ่องแท้ว่าทำไมค่า Nonce ใน PoA ถึงทำหน้าที่เป็นตัวนับ Sequence ป้องกัน Replay Attack แตกต่างจาก PoW อย่างสิ้นเชิง รวมถึงการเขียนชุดทดสอบ Automated Test ครอบคลุมทั้ง Unit Test และ E2E Test เพื่อพิสูจน์ว่าหากมีการพยายามแก้ไขบล็อกในอดีต ระบบจะตรวจพบ Chain Invalid ทันที"

---

### 5. สมาชิกคนที่ 5: Project Manager & Integration Lead
> "ในฐานะผู้จัดการโครงงาน ผมได้เรียนรู้การบริหารจัดการเวลาและการแบ่งงานตามความเชี่ยวชาญของสมาชิกทั้ง 5 คนให้สอดคล้องกับ Rubric ของรายวิชาอย่างเคร่งครัด การจัดทำ Team Charter และการประชุมติดตามงานอย่างสม่ำเสมอช่วยให้ทีมสามารถส่งมอบงานได้ตรงตามกำหนดการโดยไม่มีคอขวด การทำ Docker Containerization แบบคำสั่งเดียวช่วยให้ทุกคนในทีมรวมถึงอาจารย์สามารถรันระบบทดสอบได้อย่างสะดวกสบาย โครงงานนี้ไม่เพียงแต่ให้ความรู้ด้านบล็อกเชน แต่ยังพัฒนาทักษะการสื่อสารและการทำงานร่วมกันเป็นทีมที่มีประสิทธิภาพสูง"
