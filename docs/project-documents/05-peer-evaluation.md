# แบบประเมินผลการทำงานเพื่อนร่วมกลุ่ม (Peer Evaluation Form)

> **รายวิชา:** 4124301 เทคโนโลยีบล็อกเชนและการเข้ารหัสลับ  
> **ข้อกำหนด:** สมาชิกทุกคนต้องประเมินการมีส่วนร่วมและความรับผิดชอบของเพื่อนร่วมทีมตามเกณฑ์ประเมิน 5 มิติ

---

## 1. เกณฑ์การประเมินการทำงานร่วมกัน (Assessment Rubric 5 มิติ)

ระดับคะแนน: 5 = ดีเยี่ยม (Excellent), 4 = ดีมาก (Very Good), 3 = ปานกลาง (Satisfactory), 2 = ต้องปรับปรุง (Needs Improvement), 1 = ไม่ผ่านเกณฑ์ (Unsatisfactory)

| มิติการประเมิน | คำอธิบายเกณฑ์ |
|---|---|
| **1. ความรับผิดชอบและการตรงต่อเวลา (Responsibility & Timeliness)** | ส่งมอบงานในหน้าที่ตนเองตรงตามกำหนดการ ไม่ทำให้เกิดคอขวดในทีม |
| **2. คุณภาพของผลงาน (Quality of Work)** | ทำงานถูกต้องตามข้อกำหนด ประณีต ปฏิบัติตามมาตรฐานโค้ดและรายงาน |
| **3. การมีส่วนร่วมและการสื่อสาร (Participation & Communication)** | เข้าร่วมประชุมสม่ำเสมอ แลกเปลี่ยนความคิดเห็น รับฟัง และสื่อสารชัดเจน |
| **4. ความร่วมมือและการช่วยเหลือทีม (Teamwork & Collaboration)** | ให้ความช่วยเหลือเพื่อนร่วมทีมเมื่อพบอุปสรรค ยืดหยุ่น และมีทัศนคติที่ดี |
| **5. ความเข้าใจภาพรวมของระบบ (Overall System Understanding)** | เข้าใจภาพรวมของโครงงานครบทุกมิติ พร้อมตอบคำถามและนำเสนอร่วมกัน |

## 3. สรุปความเห็นภาพรวมของทีม (Team Consensus Summary)

* **จุดแข็งของการทำงานร่วมกัน:** สมาชิกทุกคนมีวินัยสูง มีการแบ่งหน้าที่ที่ชัดเจนตามความถนัด ทำให้การทำงานดำเนินไปได้อย่างราบรื่นและต่อเนื่องตามกระบวนการ Loop Engineering ทุกคนมีความเข้าใจในระบบและพร้อมสำหรับการนำเสนอร่วมกันในการสัมมนาวิชาการ
* **การพัฒนาในอนาคต:** รักษามาตรฐานการทำงานเป็นทีมที่ดีเช่นนี้ และนำกระบวนการวางแผนและทดสอบอย่างเป็นระบบไปประยุกต์ใช้กับโครงงานระดับปริญญานิพนธ์ต่อไป
